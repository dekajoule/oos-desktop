# wiki/

The pages of the [oos-desktop wiki](https://github.com/dekajoule/oos-desktop/wiki), kept in the tree (ADR 0007): a
change to them comes in a pull request like code, and `.github/workflows/wiki.yml` publishes the folder to the wiki
when it reaches main. Edit the pages here, never on the wiki itself: the next publish overwrites it. This README stays
in the tree.
